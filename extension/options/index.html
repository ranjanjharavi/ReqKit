Before you begin

Choose when ReqKit handles your data

ReqKit reads the active tab URL locally and stores your default URL recipe and header rules in this Chrome profile. Query values are added only when you transform a URL; header values are sent only to exact HTTPS sites you approve.

ReqKit has no analytics or developer server. Query values may be visible in browser and destination logs.
